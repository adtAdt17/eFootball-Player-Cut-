# eFootball Player Cut — Android (Offline)

هذه نسخة أولية قابلة للفتح في Android Studio، وتعمل المعالجة على الهاتف دون اتصال بالإنترنت.

## الوظائف الحالية
- اختيار صورة من الهاتف.
- إزالة الخلفية ذات اللون الموحد (أسود/أبيض/أخضر...) عبر تتبع اللون المتصل بحواف الصورة.
- تدرّج شفاف بيضاوي/دائري أسفل اللاعب.
- معاينة على خلفية مربعات توضح الشفافية.
- حفظ النتيجة PNG مع قناة Alpha في مجلد Pictures/eFootball Player Cut.

## ملاحظة مهمة
هذه النسخة لا تستخدم ذكاءً اصطناعياً لفصل اللاعب. إزالة الخلفية تعتمد على لون الحواف؛ لذلك تعطي أفضل نتيجة عندما تكون الخلفية موحدة ولا تلامس اللاعب. إذا كانت الخلفية معقدة أو من نفس لون القميص فقد تحتاج إلى ضبط شريط قوة إزالة الخلفية. التلاشي الدائري قابل للضبط.

## إنشاء APK
1. فك ضغط الملف.
2. افتح مجلد `efootball_player_cut_android` في Android Studio.
3. اسمح لـ Android Studio بتنزيل Gradle وAndroid SDK إذا طُلب ذلك (هذه الخطوة فقط تحتاج إنترنت).
4. من القائمة اختر Build > Build APK(s).
5. ستجد APK عادةً داخل `app/build/outputs/apk/debug/`.

بعد تثبيت التطبيق، اختيار الصور والمعالجة والحفظ كلها تعمل دون إنترنت.

## المتطلبات
- Android Studio حديث.
- Android 7.0 أو أحدث (minSdk 24).
- لا توجد مكتبات خارجية أو خدمات سحابية.


## بناء APK باستخدام الهاتف فقط (GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub من متصفح الهاتف.
2. ارفع جميع ملفات هذا المشروع إلى المستودع، بما فيها المجلد المخفي `.github`.
3. افتح تبويب Actions وشغّل `Build Android APK` (أو انتظر انتهاء البناء التلقائي بعد الرفع).
4. افتح عملية البناء الناجحة، ثم نزّل Artifact باسم `eFootball-Player-Cut-debug`.
5. فك ضغط Artifact وثبّت `app-debug.apk` على هاتف Android.

ملاحظة: هذه الطريقة تحتاج اتصال إنترنت أثناء بناء APK على GitHub فقط. بعد تثبيت التطبيق، معالجة الصور نفسها تعمل محلياً دون إنترنت.
